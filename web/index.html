Stream degradation sweep

BW(n) = n · S n · (S / BWseq) + (n − 1) · tseek

BWtier = min( D · BW(n),   Nnodes · RGbE / 8 )

n is disk read streams plus disk write streams, divided by the drive count. Replication doubles write streams. 10+2 erasure coding turns each logical write into 12 disk streams. The sweep holds that mix and varies n. The left axis is bandwidth. The right axis is the fraction of sequential bandwidth lost to seeks.

    Capital cost

    HDD size sweep

    Same drives, network, stream settings, prices, power, and workload. Only the HDD node count changes, rounded to a whole node. Slack is delivered bandwidth minus compute, archive, and recall. A row stays within budget when the working set fits and slack is positive. NVMe and tape stay put; the HDD cost and the power column change with the node count.

    Summary

    Usable bandwidth is delivered NVMe bandwidth plus delivered HDD bandwidth. Each is the minimum of drive bandwidth and that tier’s network. The HDD figure is one pipe: a read and a write do not run together. On a hybrid layout the shared network caps the sum. Usable HDD IOPS are that pipe divided by the segment size, plus rated NVMe IOPS. Tape is not included. Files per second use the configured file size. Capacity is NVMe plus HDD plus the tape library.

    Data flow

    Clients read from NVMe on a hit and from HDD on a miss. The read-through share of those HDD reads also passes through the NVMe cache, while the disks still perform them. Writes enter the HDD tier. Archive moves from HDD to tape and recall moves back. Each bar is bandwidth in use against what that tier can deliver; the pale remainder is reserve.

    Decimal units: 1 EB = 1,000 PB = 1,000,000 TB, and 1 GB/s = 1,000 MB/s. Network GB/s is the line rate, Gbit/s ÷ 8. A year is 365 days.
